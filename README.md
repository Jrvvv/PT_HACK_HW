# CyberSafe — обход парольной защиты

Этот репозиторий содержит два независимых способа получить доступ к скрытому хранилищу устройства CyberSafe (хакатон Positive Technologies) без знания пароля пользователем на момент начала работы.

Первый способ — автоматизированный аппаратный подбор пароля через штатный интерфейс устройства (механический энкодер), без вскрытия и без анализа прошивки. Второй — извлечение пароля напрямую из дампа флеш-памяти управляющего микроконтроллера путём статического анализа прошивки. Оба способа доведены до рабочей демонстрации и дают полный доступ к содержимому устройства, включая финальный приз, спрятанный на разблокированном томе.

## Что где лежит

`docs/hardware-bruteforce.md` описывает первый способ: устройство ESP32, эмулирующее энкодер, стенд для автоматического перебора всех 10000 комбинаций и то, как по показаниям индикаторов определяется правильный код.

`docs/firmware-reverse.md` описывает второй способ: снятие дампа флеш-памяти, поиск в прошивке функции проверки пароля и таблицы с самим паролем, а также найденные в процессе анализа альтернативные пути обхода проверки.

`docs/setup.md` — инструкция по развёртыванию стенда для перебора: прошивка ESP32, распиновка, запуск веб-интерфейса.

## Устройство коротко

CyberSafe — это плата на базе микроконтроллера RP2040 (Raspberry Pi Pico) с механическим энкодером для ввода четырёхзначного PIN-кода и набором светодиодов, показывающих текущую позицию ввода. При подключении к компьютеру устройство не определяется как USB-накопитель до тех пор, пока не будет введён верный код — после этого на хосте появляется скрытый ранее том с данными.

## Найденный пароль

**3736**. Подтверждён двумя независимыми путями: восстановлен статическим анализом прошивки (см. `docs/firmware-reverse.md`) и повторно найден автоматическим перебором на стенде (см. `docs/hardware-bruteforce.md`).

## Результат

После ввода верного кода устройство поднимает USB-накопитель `PositiveLabs Flash MSC` (идентификатор `cafe:4000`), на котором лежит финальный файл-приз. Дамп этого тома, извлечённые файлы и контрольные суммы находятся в `firmware/dumps/`.

## Содержимое репозитория

| Путь | Содержание |
|---|---|
| `docs/` | Подробное описание обоих способов и инструкция по стенду |
| `esp/` | Прошивка ESP32, эмулирующая энкодер и кнопку устройства |
| `host/` | Управляющий сервер, веб-интерфейс перебора и вспомогательные скрипты измерений |
| `tools/pin_model.py` | Скрипт, который вычисляет пароль напрямую из дампа флеш-памяти |
| `firmware/dumps/` | Дамп флеш-памяти платы и содержимое разблокированного тома |
| `logs/` | Логи одного из прогонов перебора и результаты вспомогательных измерений |
| `board_map.json` | Распиновка соединения ESP32 и платы устройства |

## Контрольные суммы

Актуальные хеши файлов из `firmware/dumps/` — в `logs/DUMPS_SHA256.txt`.
